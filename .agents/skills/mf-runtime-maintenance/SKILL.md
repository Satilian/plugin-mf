# Поддержка runtime

Сначала прочитать корневой AGENTS.md и соответствующие разделы README.

- Проследить цепочку фасад → платформенный runtime → React/core → transport/protocol или серверный Loader.
- Сохранять release pinning на время SSR-запроса и карту релизов в HTML. Вложенные remote bundles разделяют AsyncLocalStorage через существующий Symbol.for; не заменять его независимыми локальными контекстами.
- Серверный CSS берётся из client-манифеста того же релиза. Только HTTP 404 указателя разрешает legacy layout.
- Loader отвечает за память и ESM import; DiskCache — за файлы. Ключ включает provider, releaseId и полные URL файлов.
- Проверка готовности, публикация, leases и очистка выполняются под общей межпроцессной блокировкой. Не сужать критическую секцию без проверки гонок.
- Дождаться всех файлов перед удалением staging и атомарной публикацией. Не заменять Promise.allSettled на ранний выход при ещё работающих записях.
- Активные leases защищают файлы на время жизни процесса. Очистка диска не выгружает ESM Node; новую версию выбирают новым URL.
- Проверки выбирать по mf-change-verification. Не добавлять retries, таймауты и новые политики кеша под видом рефакторинга.
